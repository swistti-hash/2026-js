### Практика 01 — пиксельные часы

В папке `01/` находятся HTML, CSS и JavaScript. Откройте `01/index.html` в браузере: установка пакетов и сервер не нужны.

Реализованы описания всех цифр от 0 до 9, вывод текущего времени в формате ЧЧ:ММ и автоматическое обновление (задание со звёздочкой). Используется местное время компьютера, на котором открыта страница.

### Как устроено решение

1. `digits` содержит массивы координат закрашенных клеток. Первый элемент пары — строка, второй — столбец, нумерация с нуля. Размер каждой цифры — 9 строк и 5 столбцов.
2. `createTable` создаёт HTML-таблицу, как на практике.
3. `getTimeDigits` получает часы и минуты через `Date`, дополняет их нулём слева и возвращает четыре символа.
4. `drawDigit` закрашивает клетки по координатам нужной цифры.
5. `updateClock` обновляет четыре цифры, а `setInterval` проверяет время каждую секунду. Таблицы перерисовываются только при изменении минуты.

### Редактор цифр

Под часами сохранён и дополнен редактор из практики (`createClickableTable`). Выберите цифру, нажимайте на клетки и сохраните результат кнопкой SAVE. Новое начертание сразу применяется к часам и галерее. Поле JSON показывает описания всех десяти цифр в формате массивов координат. Изменения действуют до перезагрузки страницы; чтобы оставить их в исходном коде, перенесите JSON в объект `digits`.
